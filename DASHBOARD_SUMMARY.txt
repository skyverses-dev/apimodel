USER DASHBOARD (Regular Users)
─────────────────────────────────────────────────────────────────────────────
1. balance (number)
   - Main account balance in credits
   - Source: EzAI API
   - Display: Balance stat card, Plan hero card
   - Color: Green if positive, Red if negative

2. plan_type (string)
   - Current plan type
   - Values: starter, pro, max, ultra, one_time, none
   - Source: EzAI API
   - Display: Plan badge with color coding

3. daily_limit (number)
   - Daily free credits limit (resets every 5h UTC)
   - Source: EzAI API
   - Display: Free Credits box, Rate limits section

4. daily_used (number)
   - Credits used in current 5-hour cycle
   - Source: EzAI API
   - Display: Free Credits box, Progress bar

5. plan_expires_at (string | null)
   - Plan expiration date
   - Source: EzAI API
   - Display: Expiration badge in hero card

6. spending_today (number)
   - Total credits spent today
   - Source: EzAI usage logs (calculated server-side)
   - Display: Spending Today stat card
   - Format: Fixed to 4 decimal places

7. requests_today (number)
   - Number of API requests made today
   - Source: EzAI usage logs (counted server-side)
   - Display: Requests Today stat card, Daily requests limit

8. spending_30d (number)
   - Total credits spent in last 30 days
   - Source: EzAI usage logs (calculated server-side)
   - Display: Spending (30 days) stat card
   - Format: Fixed to 2 decimal places

9. transactions[] (Array<EzaiTransaction>)
   - Recent account transactions
   - Source: EzAI API (limited to 20 most recent)
   - Display: Transactions table
   - Fields per transaction:
     • date (created_at)
     • type (topup, plan_activate, user_create, user_deactivate, plan_deactivate)
     • amount (with +/- indicator)
     • description (or failure_reason)
     • status (success, failed, completed, error)

For each user, displays:
- name, email
- balance
- plan_type (with badge)
- daily_used / daily_limit (with progress bar)
- plan_expires_at (days until expiration)
- Sorting: by daily_used (descending)
- Color coding: 90%+ red, 70%+ yellow, <70% purple

USAGE HISTORY TABLE
─────────────────────────────────────────────────────────────────────────────
Per request log:
- created_at → Formatted timestamp (vi-VN locale)
- model → Model name (Claude, GPT-4, etc.)
- request_path → API endpoint called
- input_tokens → Input token count (formatted K/M)
- output_tokens → Output token count (formatted K/M)
- cache_read_tokens / cache_write_tokens → Cache stats
- cost → Cost in credits (6 decimal places)
- status_code → HTTP status (green if 200, red otherwise)

===============================================================================
                             DATA SOURCES
===============================================================================

EzAI API
─────────────────────────────────────────────────────────────────────────────
- ezai.getUser() → balance, plan_type, daily_limit, daily_used, plan_expires_at
- ezai.getTransactions() → transactions array
- ezai.getAllUsage() → usage logs for spending/request calculation
- ezai.listUsers() → all users (admin only)

MongoDB Collections
─────────────────────────────────────────────────────────────────────────────
- User collection → user profile data
- TopupRequest collection → monthly top-up history (status='approved')

Server-Side Calculations
─────────────────────────────────────────────────────────────────────────────
- spending_today → Sum of cost from usage logs where created_at >= today start
- requests_today → Count of usage logs where created_at >= today start
- spending_30d → Sum of cost from usage logs where created_at >= 30 days ago

GET /api/usage
─────────────────────────────────────────────────────────────────────────────
Request: None (uses session for authentication)
Response: UsageData {
  balance: number
  plan_type: string
  daily_limit: number
  daily_used: number
  plan_expires_at: string | null
  transactions: EzaiTransaction[]
  monthly_topup_vnd: number
  monthly_topup_credit: number
  spending_today: number
  requests_today: number
  spending_30d: number
}
Refresh Rate: 30 seconds (SWR polling)
Auth: Required (session)

GET /api/usage/history?page=1&limit=20
─────────────────────────────────────────────────────────────────────────────
Query Params:
  - page: number (default 1, min 1)
  - limit: number (default 20, min 5, max 100)
Response: {
  usage: EzaiUsageLog[]
  total: number
  page: number
  limit: number
}
Refresh Rate: 60 seconds (SWR polling)
Auth: Required (session)

GET /api/admin/stats
─────────────────────────────────────────────────────────────────────────────
Request: None
Response: {
  stats: AdminUserStat[]
  total: number
}
Refresh Rate: 30 seconds (SWR polling)
Auth: Required (admin role only)
